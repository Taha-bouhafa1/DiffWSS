# DiffWSS
### Diffusion-Guided Weakly Supervised Semantic Segmentation of High-Resolution Aerial Images

DiffWSS is a research project investigating diffusion-guided representations for Weakly Supervised Semantic Segmentation (WSSS) of high-resolution aerial imagery.

The project adapts the methodology introduced in **Diffusion-Guided Weakly Supervised Semantic Segmentation (DiG, ECCV 2024)** to the ISPRS Potsdam dataset.

The main objective is to investigate whether diffusion models can improve semantic localization and pseudo-label generation using image-level annotations instead of expensive pixel-level annotations.

---

## Research Motivation

Semantic segmentation of aerial imagery is important for applications such as urban mapping, land-cover analysis, and geographic information systems. However, obtaining pixel-level annotations for high-resolution aerial images is expensive and time-consuming.

Weakly Supervised Semantic Segmentation offers an alternative by learning segmentation models from weaker annotations, such as image-level class labels.

Conventional Class Activation Maps (CAMs) often highlight only the most discriminative regions of an object, resulting in incomplete localization and noisy pseudo-labels.

Diffusion models offer complementary visual representations that may help improve semantic localization and pseudo-label quality.

This project investigates the potential of integrating diffusion representations into weakly supervised semantic segmentation for high-resolution aerial imagery.

## Research Question

**Can diffusion-guided representations improve semantic localization, pseudo-label generation, and segmentation performance in weakly supervised semantic segmentation of high-resolution aerial images using only image-level annotations?**

The investigation focuses on:

- Evaluating conventional CAM-based weakly supervised segmentation.
- Investigating the contribution of diffusion-guided features to semantic localization.
- Evaluating the roles of LFCA and PAC in improving localization and representation consistency.
- Comparing weakly supervised performance with a fully supervised segmentation reference.

---

## Experimental Design

Three experiments are planned to evaluate the proposed approach.

### Experiment 1: Conventional CAM + DeepLabV3+

**Weakly Supervised Baseline**

This experiment establishes a conventional CAM-based weakly supervised segmentation baseline without diffusion guidance.

Workflow:

1. Train a classification network using RGB training images and image-level class labels.
2. Generate Class Activation Maps (CAMs).
3. Refine CAMs and generate pseudo-labels.
4. Train DeepLabV3+ using the generated pseudo-labels.

**Objective:** Establish baseline performance using conventional CAM-based localization and weak supervision.

### Experiment 2: DiG Adaptation + DeepLabV3+

**Proposed Diffusion-Guided Weakly Supervised Approach**

This is the main experiment of DiffWSS, adapting the DiG framework to the ISPRS Potsdam dataset.

The approach combines aerial-pretrained visual representations with diffusion-model features through two main components, LFCA and PAC.

#### 1. Aerial Encoder and Encoder-CAM

A SatlasPretrain Aerial RGB Swin-B encoder extracts semantic representations from the input aerial images.

The aerial encoder replaces the ImageNet-pretrained ViT used in the original DiG setup to reduce the domain gap between natural images and high-resolution aerial imagery.

A compatibility wrapper exposes DiG-style attention, class, and CAM outputs so the encoder can be used with LFCA and PAC.

#### 2. Diffusion Model and Diffusion-CAM

A Denoising Diffusion Probabilistic Model (DDPM) is trained on unlabeled training images.

Intermediate features extracted from its U-Net provide complementary visual representations.

Diffusion-CAM is generated by integrating diffusion features with aerial encoder representations through Locality Fusion Cross Attention.

#### 3. Locality Fusion Cross Attention (LFCA)

LFCA combines semantic information from the aerial encoder with intermediate diffusion features through cross-attention.

This fusion aims to improve semantic localization and produce more informative activation maps.

#### 4. Patch Affinity Consistency (PAC)

PAC encourages consistency between representations extracted from original input images and their diffusion-reconstructed counterparts.

It exploits patch-level relationships to improve the consistency of learned semantic representations and localization.

#### 5. Pseudo-Label Generation and Segmentation

The localization maps are refined to generate pseudo-labels.

DeepLabV3+ is subsequently trained using these pseudo-labels to produce pixel-level semantic segmentation predictions.

**Objective:** Investigate whether diffusion-guided localization and patch affinity consistency improve weakly supervised segmentation compared with conventional CAM-based methods.

### Experiment 3: Fully Supervised DeepLabV3+

**Fully Supervised Reference**

This experiment trains DeepLabV3+ directly using the original pixel-level Potsdam annotations.

Workflow:

1. Use RGB training images and their corresponding ground-truth segmentation masks.
2. Train DeepLabV3+ using pixel-level supervision.
3. Evaluate the model on the held-out test set.

No CAM generation or pseudo-label generation is required.

**Objective:** Establish a fully supervised reference and measure the performance gap between weakly supervised and fully supervised segmentation.

### Experimental Comparison

| Experiment | Method | Supervision | Segmentation Model |
|---|---|---|---|
| E1 | Conventional CAM | Image-level labels | DeepLabV3+ |
| E2 | DiG adaptation: aerial Swin-B CAM, Diffusion-CAM, LFCA and PAC | Image-level labels | DeepLabV3+ |
| E3 | Ground-truth segmentation masks | Pixel-level annotations | DeepLabV3+ |

The main comparison is between E1 and E2 to investigate the contribution of diffusion guidance.

E3 provides a fully supervised reference for evaluating the performance gap.

## Dataset

The project uses the **ISPRS Potsdam 2D Semantic Labeling Dataset**, which contains high-resolution aerial images with pixel-level annotations.

### Dataset Characteristics

- Number of scenes: 38
- Original image resolution: 6000 × 6000 pixels
- Spatial resolution: 5 cm
- Number of semantic classes: 6
- Image format: RGB TIFF
- Annotation format: RGB TIFF masks

### Semantic Classes

| ID | Class | RGB Color |
|---|---|---|
| 0 | Impervious surfaces | (255, 255, 255) |
| 1 | Building | (0, 0, 255) |
| 2 | Low vegetation | (0, 255, 255) |
| 3 | Tree | (0, 255, 0) |
| 4 | Car | (255, 255, 0) |
| 5 | Clutter / Background | (255, 0, 0) |

### Preprocessing

The original 6000 × 6000 images are divided into non-overlapping 512 × 512 patches.

- Patch size: 512 × 512
- Stride: 512
- Padding: Images are padded to 6144 × 6144.
- Patches per scene: 144
- Total patches: 5,472

### Dataset Split

The dataset is divided at the scene level to prevent spatial leakage between training, validation, and testing samples.

| Split | Scenes | Patches |
|---|---:|---:|
| Training | 26 | 3,744 |
| Validation | 6 | 864 |
| Testing | 6 | 864 |
| **Total** | **38** | **5,472** |

Image-level class labels are generated from training annotations to simulate weak supervision.

For E1 and E2, pixel-level annotations are reserved for evaluation. E3 uses pixel-level training annotations as it is fully supervised.

## Methodology

The project adapts the Diffusion-Guided Weakly Supervised Semantic Segmentation (DiG) framework to high-resolution aerial imagery.

### Stage 1: Diffusion Model Training

A Denoising Diffusion Probabilistic Model (DDPM) is trained on unlabeled Potsdam training images.

The diffusion model learns visual representations of the target aerial imagery and provides intermediate features for the subsequent weakly supervised learning stage.

**DDPM Configuration:**

- Architecture: U-Net
- Diffusion timesteps: 1,000
- Noise schedule: Sigmoid
- Prediction objective: Velocity prediction (`pred_v`)
- Optimizer: Adam
- Learning rate: 1e-4
- Mixed precision: FP16
- EMA: Exponential Moving Average

### Stage 2: Diffusion-Guided Weakly Supervised Learning

The second stage combines aerial-pretrained semantic representations and diffusion-model features.

It incorporates:

- Satlas Aerial Swin-B feature extraction with DiG-compatible CAM outputs.
- Diffusion-CAM generation.
- Locality Fusion Cross Attention (LFCA).
- Patch Affinity Consistency (PAC).
- Checkpoint selection using CAM-based mIoU instead of validation loss alone.

The resulting localization maps are used to generate pseudo-labels for downstream semantic segmentation.

### Semantic Segmentation

DeepLabV3+ is used as the downstream segmentation architecture to learn pixel-level predictions from the generated pseudo-labels in the weakly supervised experiments.

---

## Evaluation

The experiments will be evaluated using standard semantic segmentation metrics:

- Mean Intersection over Union (mIoU).
- Per-class Intersection over Union (IoU).
- Overall Accuracy (OA).
- Mean Pixel Accuracy.
- Precision, Recall, and F1-score where appropriate.

The same scene-level split will be maintained across experiments to ensure consistent comparisons.

## Implementation

The project is implemented using Python and PyTorch.

### Main Technologies

- Python
- PyTorch
- SatlasPretrain Aerial Swin-B
- Denoising Diffusion Probabilistic Models (DDPM)
- Locality Fusion Cross Attention (LFCA)
- Patch Affinity Consistency (PAC)
- DeepLabV3+
- ISPRS Potsdam Dataset
- Modal for GPU training

### Current Implementation Notes

- E2 uses `SatlasPretrain Aerial Swin-B` (`Aerial_SwinB_SI`) as the visual encoder.
- `src/models/satlas_swin.py` adapts the Swin-B backbone to the DiG-style interface expected by the model, including `q`, `cls`, `pcls`, `cams`, and `rcams`.
- `train_modal.py` is the GPU training entrypoint on Modal, using an L40S GPU and writing to `diffwss_run_60_satlas`.
- The trainer evaluates CAM mIoU across thresholds `0.35` to `0.69` and saves the best-mIoU checkpoint as `best.pt`.
- Generated checkpoints, plots, and visualization outputs are intentionally ignored by Git.

### Hardware

The DDPM phase used GPU acceleration on Kaggle T4 GPUs, while the current E2 training run uses a Modal L40S GPU.
